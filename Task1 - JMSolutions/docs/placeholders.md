# Placeholders Used

The following placeholders are used throughout the UI and require client input before final deployment:

- `[PHONE]` - Phone number
- `[EMAIL]` - Email address
- `[ADDRESS]` - Physical address
- `[CITY / SERVICE AREAS]` - Service locations
- `[HOURS]` - Operating hours
- `[LEGAL NAME]` - Company legal name
- `[LICENSE #]` - State HVAC/Refrigeration License Number
- `[INSURANCE]` - Insurance details
- `[CERTIFICATIONS]` - Certifications
- `[YEARS IN BUSINESS]` - Years active
- `[FOUNDER NAMES]` - Founder names
- `[REVIEWS + RATING]` - Review scores
- `[GOOGLE_REVIEW_URL]` - Link to Google reviews
- `[BOOKING_URL]` - Link to booking portal
- `[SOCIAL LINKS]` - Links to social profiles
- `[PLAN PRICES]` - Maintenance plan pricing
- `[FINANCING INFO]` - Financing provider details
- `[SITE URL]` - Production website URL
- `[Placeholder: Walk-in Cooler Image - No People]` - A placeholder for a real image to ensure compliance with the "no women/girls" hard constraint.
